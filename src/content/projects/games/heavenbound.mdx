# ABOUT
Ezra the Guardian Angel was exploring Earth, trying to find their assignee, when all of a sudden a demon comes from nowhere and kicks them down to the pit of the earth. You must help Ezra get back to heaven to reconnect him to his person!

# ROLE
For *Heavenbound*, I wanted to create a simple game that was easy to pick up and play, but also had a unique art style and fun gameplay. I created the game in Unity, using C# for scripting Aseprite for all the sprites in the game. I also created all of the sound effects for the game using various tools provided to me.
